# Archive of Scone

Responsive, static portfolio site. Open home.html for the landing page, index.html for the Live2D gallery, design.html for the Design page, or contact.html for the contact page; no build step is required.

The masthead artwork is stored at assets/archive-of-scone-logo.jpg. Replace that file to update the illustrated title while keeping the same filename.

## Add an artwork

1. Put the image in assets/.
2. Add an entry to the artworks list at the top of script.js with a title, category, image path, description, and tags.

The gallery automatically paginates after nine works. Square thumbnails focus near the top of each portrait; adjust object-position in style.css if a character's face sits elsewhere. The popup displays the full illustration.

## Before publishing

Replace the placeholder X, email, and Artmug details in contact.html. The included sample sheets visibly contain sample watermarks; replace them with approved portfolio images before public sale or promotion.

To publish with GitHub Pages, push these files to a GitHub repository, then enable Pages for the chosen branch and folder in the repository's Pages settings.
